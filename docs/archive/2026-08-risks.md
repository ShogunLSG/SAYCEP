# Open Risks

Live status of the project's load-bearing risks. Update the status line when a
risk moves. The three seeded risks come from CLAUDE.md.

---

## Risk 1 — Job data source (ESSA API assumed to exist)

**Status (2026-08-03): Largely resolved — moving to Adzuna.**

ESSA has no known public API; it is a login-gated JSF portal requiring an SA ID
number, confirmed by a Phase 0 search. Adzuna covers South Africa on a free
developer tier and is the chosen source. See ADR-0001 in DECISIONS.md.

Residual risk: Adzuna's real SA listing volume is unverified until a live call is
made with a registered key. Until that check passes, ADR-0001 stays Proposed.

## Risk 2 — LLM cost per roadmap generation is unmeasured

**Status (2026-08-03): Open — untouched.**

Phase 0 spike "What does one roadmap cost?" not yet run. Requires the sandbox
(currently down: hardware virtualization disabled in firmware) to execute
prompts and count tokens. Until measured, treat any design that generates
roadmaps in bulk as suspect.

## Risk 3 — Reliable structured output from the LLM is unproven

**Status (2026-08-03): Open — untouched.**

Phase 0 spike "Can the LLM reliably return structured output?" not yet run.
Requires the sandbox. Until it's tested, assume a repair-and-retry layer may be
needed and treat that as a design decision, not an afterthought.

---

## Environment blocker (not a project risk, but blocking Phase 0)

The Cowork Linux sandbox cannot start on this machine — hardware virtualization
(Intel VT-x / AMD-V) is disabled in BIOS/UEFI (`HRESULT 0x80370102` /
`HYPERVISOR_VIRT_DISABLED`). This blocks running any code, executing LLM prompts,
and unzipping archives, which in turn blocks Phase 0 spikes 2 and 3. Fix: enable
virtualization in firmware and reboot. Research and document work is unaffected.
